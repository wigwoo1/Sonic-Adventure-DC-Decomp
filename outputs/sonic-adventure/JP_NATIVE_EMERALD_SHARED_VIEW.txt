Shared Emerald Coast POINT view on Windows

The scene verifier captures the POINT matrix from Sonic's final
live walk position while the stage session is still open. The same
view drives terrain, ring models, and pickup sparkles. The fixture
cancels the old terrain translation and removes the ring overlay's
diagnostic rebase. The caller's matrix is restored afterward.

Run verify_native_emerald_shared_view.py against the qualified POINT
camera build and the same local disc and scene inputs. The 473-check
run verifies retained terrain, ring and sparkle packets, textured
and vertex-coloured presentation, and the walking pickup audio.

This capture uses a shared camera projection with the fixture's
terrain selection and layered pre-pickup and sparkle submissions.
The full stage loop, camera smoothing, and camera collision remain
open. Overall project completion is about 10%.
