Status: VERIFIED for the decoder/expander and output tests below. Live game

What now runs
The native sound graph includes the original ADX header readers, integer mono
and stereo block decoders, floating stereo decoder, quantizer tables and all
eight expander records. Original SDK source stays in private generated files.
An authored coefficient adapter executes the original single-precision formula,
runtime cosine reduction/series and RZ/DN1 scalar semantics using existing frame
math and preserved integer FLOAT/FTRC helpers. Default500Hz/44100Hz coefficients
are7334 and-3283. Valid audio-rate/cutoff coefficient values are verified; broader
libm errno/trap semantics are not claimed by this value adapter.

Native pointer fields retain64 bits. The original52-byte guest expander becomes
72 bytes on PC. There is one actual pool, not a fake handle table. Raw SDK entry
points remain internal, caller-owned interfaces; the future stream owner must
validate formats/buffer lengths and control their lifetimes before calling them.
This milestone does not install a public game stream owner or background ADXT
service. No success-only ADXT or stream functions have been added.

The integer decoder keeps signed-nibble prediction,16-bit clipping,32-bit wrap
and the original end-marker behavior. The floating stereo decoder keeps its
unclamped floating history and original FMUL followed by two FMAC operations.
FLOAT/FTRC, unsigned shifts and byte swaps avoid undefined host C behavior.
Odd stereo block counts, early-return history and the expander's actual internal
error flag retain their original behavior; these are not silently corrected.

Remaining integration
The original stream task compiles in an unexecuted audit. Its link still needs
12 genuine frontend APIs: ADXF_LoadPartition; ADXT_Create, Destroy, EntryErrFunc,
GetStat, GetTime, SetAutoRcvr, SetOutVol, SetSvrFreq, StartAfs, StartFname and Stop.
The audit also reports adxpd_internal_error: that state already exists in this
decoder module and must be colocated with the stream task or imported properly,
rather than duplicated. The actual stream constructor remains unexecuted because
it still contains fixed STREAM_WORK0x0cca8000. Replace that with owned storage.

output test above is a qualification client, not that completed integration.
The full sound module's other stage/player/editor providers, complete original
sound_send_queue and higher main/gameplay remain required too.
