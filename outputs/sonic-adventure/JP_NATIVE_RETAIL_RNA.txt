Status: VERIFIED for the bounded retail prefix described here. Overall project

What changed
The existing native audio graph now has direct integration evidence using the
actual supplied Japanese TITLE.ADX. Its original GDFS implementation opens the
retail file, issues a nonblocking sector read, services actual native I/O, runs
its original completion callback and closes the handle. Every returned byte
agrees with an independent read-only ISO parser. No alternate media owner or
file-read stub provides the decoder's input in this qualification.

That native input flows through original SJMEM, ADXSJD, ADXB/ADXPD, contiguous
stereo output joints, RNA/mwSnd, original SDK PCM ports and actual MASARU sound
firmware. This extends the earlier separately qualified decoder and authored-
waveform RNA tests to one real music pipeline. Existing DLL bytes are unchanged;
this milestone adds integration tests, an independent oracle and evidence.

The original header is 36 bytes long and declares 2,540,372 stereo frames at
44100Hz. The test supplies its unmodified first 99,252 bytes: the header plus
99,216 compressed bytes for 88,192 frames, just under two seconds. It neither
rewrites the song's length nor appends an invented end marker. The memory joint
exposes only that exact prefix after the actual sector-rounded file read.
The decoder remains in its original DECODE state at the longer song's prefix
boundary. Explicit stop/destroy retires it; no full-song completion is claimed.

Private playback sample and limitations
The local native-JP-title-SJD-RNA-AICA-demo.wav is actual mixed firmware output
from the bounded title segment. It stays private with the retail source, sound
RAM and PCM captures. No new graphical scene was tested, so no new screenshot
is available. The sample can be played locally; this particular deterministic
test renders offline rather than running a live Windows audio worker. Earlier
authored-stream RNA and output qualifications cover the shared timed worker.

This is not yet the full ADXT/ADXF/ADXSTM game music/voice scheduler. The test
requests a finite title prefix and provides memory input to SJD after its native
file read. Continuous file-ring refill, full-song completion/looping, archive
voice selection, track switching, cancellation during playback and real timed
retail streaming still require verification through the complete game frontend.
