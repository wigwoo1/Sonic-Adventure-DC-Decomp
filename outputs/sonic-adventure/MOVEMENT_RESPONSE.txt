Original behavior recovered
- 075416: 280 instructions, 28 branch outcomes. It reads the query's contact
  count at +28 and the original 88-byte contact records at 8c6bacf0. It calls
  the actual distance and signed-angle helpers, filters normals, limits velocity
  in the R5 record and movement in the R7 query, and returns a response flag.
  R6 supplies state including the speed limit at +c4; the original caller's
  fifth argument is a flag word at the initial stack pointer. Successful
  geometric owner tests use ordinary PR0/SZ0 modes.
- 055dac: 44 instructions, four outcomes. It forms a dot product, calls the
  actual acos wrapper, converts the result to the game's angle units, and forms
  a cross product. An optional R6 sign vector can select 65536 minus the angle.
- 638eac: 13 instructions. It adds the R5 vector into the R4 vector, retaining
  original load/store ordering, register effects and paired-transfer behavior.
- 639b50: 36 instructions. It writes R4 cross R5 through R6 and returns its
  length in FR0, using the original FMAC, FIPR and FSQRT order. This differs
  from the already recovered 027360 helper, which crosses two point differences.
- Canonical 63a970: five instructions. It uses the low 16 bits of the phase
  with FSCA, then transfers the cosine result. Its earlier registry entry is
  retained and receives no new original-routine credit.

An allegedly unreachable path is actually reachable
Ghidra's C draft omitted the zero-length branch at 075626. The original
instruction listing retains it, and an actual call sequence now executes it.

An original vector-add call first produces -1 or 0 in old stack RAM. The
response routine subsequently allocates its own frame. With a contact distance
of 1001, its initial minimum of 1000 is never replaced and the selected index
stays -1. The later indexed read consequently uses the old word at frame+64,
immediately before the distance array. If the velocity pointer overlaps the
query's movement vector, the original head-on velocity clear also clears that
movement. Zero is greater than the negative old word, so the later zero-length
branch executes. Disjoint buffers and a zero old word provide matching controls.

The producer and response both run from their ordinary original entry points.
No callee result, return address or execution frame is installed. Only initial
RAM inputs and ordinary call arguments are supplied. This demonstrates the
original raw alias/history behavior; it does not establish that the game's
natural object layout uses this case. No original branch is removed or excluded.
