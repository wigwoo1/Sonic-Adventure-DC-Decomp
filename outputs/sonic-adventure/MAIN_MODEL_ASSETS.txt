What changed
model_asset_inventory.py is a read-only bounded parser for the basic model layout
consumed by the recovered code: 40-byte model records, 24-byte segment records,
20-byte materials and 52-byte object nodes. It inventories vertex/normal arrays,
material selectors, topology/group streams and optional signed UV arrays. It checks
image bounds, pointer alignment, finite vectors, positive bounded counts, material
indices and vertex indices. Alternate c000 strips use the high count bit as a
winding flag; their length is the low 15 bits. The 8000 group length is unsigned.
Descriptive field names remain inferred from original instructions.

The original mask at 8c620cb0 is 03600000 hex and the material-index mask at
8c620b62 is 3fff. Twelve original literal profile values map to nine renderer
families, including the original alias profiles. Runtime material masks/overrides
are separate from this static classification. The parser preserves rejected
headers and does not count structural discovery as recovered game code.

Native original-asset checks
A separate DLL links the existing recovered native renderer chain. Selection is
reproducible: the smallest node-backed example of each of the nine families,
every inventoried model containing 8000 groups, and both known particle roots,
deduplicated to 24 original models. Their model, vertex, normal, material, segment,
index and UV bytes remain exactly unchanged before and after every test.

Runtime camera matrices, projection settings, command buffers and bounded texture
descriptors are constructed. Texture descriptors stand for loaded textures; their
pixels and physical GPU texture memory are not supplied. Both the inactive FPU
matrix bank and published matrix memory are initialized consistently, as required
by the recovered caller contract. The runtime vertex limit is set to a valid
capacity, rather than the old four-vertex synthetic-fixture limit.

Limits and next work
This bounded aligned scan covers one original executable. It does not discover all
possible game models, runtime allocations, relocations or alternate model formats.
Finite/vector/count bounds and positive valid groups are explicit inventory
preconditions; other records may exist outside them. Object-node searches bound
flag values and validate pointers/transforms but do not establish gameplay calls.
No asset names were guessed. Optional unused segment attribute fields are not
semantically decoded by this parser.

The numerical backend, coherent-RAM/MMU-off queues, inherited guards and simulated
runtime scope remain. No hardware NaN precision, GPU pixels/cache timing, complete
frame driver or gameplay is proved. The new strict build and focused suites ran;
the historical aggregate workflow and particle lifetime suite were not rerun in
this checkpoint. Their previous pinned evidence remains preserved.
