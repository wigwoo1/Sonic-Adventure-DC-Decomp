The 230-source build adds the complete original chain validator, 64b300:

The validator uses the original filename search, raw directory decoder and
selected BE/LE FAT reader. A missing file returns -251; an invalid chain returns
-191. The final link must be 0xFFFA. Intermediate links reject self-links,
0xFFFA, 0xFFFC, 0xFFFF and values at or above the declared limit. A zero-block
file still checks its head bound but performs no FAT lookup. There is no added
cycle detector or iteration cap: the original declared block count bounds the
loop, and the cycle test follows that count before rejecting a wrong final link.
