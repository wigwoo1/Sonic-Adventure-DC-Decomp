Observed morph behavior
Appearance+20/+24/+28 provide X/Y/Z parameters. Exactly zero X or Y is replaced
by original constant 3727c5ac (approximately 0.00001); their signs choose the
positive/negative source tables, then their magnitudes become weights a and b.
The unchanged source lists select 12 mesh nodes for type 0 and 14 for other
types, plus a separate set of 22 object-position nodes.
For a scalar position/normal component, using neutral source N, sign-selected
sources X/Y and original base B, the observed mathematical expression is:
  shape = (a*(a*X + (1-a)*N) + b*(b*Y + (1-b)*N)) / (a+b)
  output = z*shape + (1-z)*B
Native C preserves the exact original FMUL/FMAC/FDIV order and rounding rather
than replacing these steps with the combined expression. Normals are blended
without an added normalization pass. The 22 object positions use the same
source selection and blend. Zero vertices/materials and missing mesh models
follow original branches, including an early return for a missing mesh model.

Material diffuse B/G/R channels use the analogous blend, first clamped to
0..255. Material-only Z is capped at 1, with no added lower cap. The blend with
base colour is truncated, reduced to an unsigned byte and converted back to
float before the original final clamps. Negative extrapolation can therefore
wrap a channel; tests preserve that ordering. Appearance flag 02 instead
writes 85 to the three channels. Node index 27 skips the material stage. Other
material fields, including alpha, IDs and flags, are retained. The first
material's B/G/R and ff alpha are also written to entity+8c4..8c7 (hex).

The word-copy helper receives byte count in R0, destination R1 and source R2.
Counts 0/4/.../64 select one of 17 internal targets, copying words in descending
address order. The larger loop copies words forward and retains its original
extra read and register effects. These distinct overlap behaviors are tested;
no generic memcpy/memmove semantics are substituted. Small unaligned table
indices stop at an unsupported computed jump. The morph calls it with count
58 hex (88 bytes) to copy the original 22-index object-position list to stack.

Guest state and guards
All dynamic RAM operations validate their reached address and transfer width
before effects. Unsupported computed jumps and changed return PR also stop
at their original boundary. The new bridges preserve explicit FPUL and MACL
state; FLOAT/FTRC updates are visible through the complete initializer.
FMOV retains FR/SZ bank, width, overlap and pointer increments. PR=1 stops at
reached FLDI0; unsupported numeric modes/states and modeled arithmetic traps
retain exact reached partial state. These are bounded host stops, not hardware
MMIO, alignment or CPU exception delivery. The existing independent SH-4
numerical support is reused; no numerical backend source was changed.
