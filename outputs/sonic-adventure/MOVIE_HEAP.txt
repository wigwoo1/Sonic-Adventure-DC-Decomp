What the original code does
Allocation adds 31 to the request with 32-bit wrapping arithmetic, converts it
to 32-byte units and adds a header unit. It searches the circular free list from
the current cursor's successor. An exact match is unlinked; a larger block is
trimmed at its end. The cursor is updated and the payload pointer is returned.
A complete unsuccessful pass returns null. Interrupt-mask and stack/register
effects remain original. The very-large-request wrapping behavior is preserved;
this recovery does not introduce a different validated host allocation policy.

The initializer aligns the supplied pool upward and size downward to 32 bytes,
stores the pool/size globals, creates the fixed sentinel at 8c88ef1c, and invokes
the actual original release routine to insert the pool. Release finds the
address-ordered insertion point, joins an adjacent successor and/or predecessor,
updates the circular links/cursor, and restores the interrupt mask. Releasing
null follows its original no-op path. Native code does not substitute malloc,
an allocation pointer, a release callback, or a successful result.
