Parameter behavior
Entity+ec points to appearance data. Stored X/Y at appearance+20/+24 are
clamped independently to [-1.5,1.5]; the clamp itself does not request a morph.
Each coordinate then approaches entity targets +dc/+e0 by raw step 3b449ba5
(approximately 0.003). Positive and negative adjustments are separate tests.
An overshoot can add then subtract on one call, retaining the morph request.
This is preserved rather than replaced by an else-if or snapping algorithm.

Appearance flag halfword +36 bit 0 requests an event. The helper clears only
that bit and adds raw 3c03126e (approximately .008) to target Z for type 0,
or 3b83126e (approximately .004) for other types. For four current/peak pairs
at +0c/+54, +0e/+56, +10/+58, +12/+5a, a current below its peak gains 10
with 16-bit wrapping. The corresponding target changes by raw 3ac49ba5
(approximately .0015), in order: Y minus, Y plus, X plus, X minus.
Peaks are then updated to max(peak,current). Unsigned halfword ordering and
wrap cases around 32767/32768 and 65535 are tested explicitly. These event
changes do not directly set the morph-request flag.

Target Z at entity+e4 is capped above at 1.5, with no lower clamp here.
If target Z exceeds stored appearance+28, the stored value gains the same
.003 step and requests a morph. If stored Z exceeds target Z, it copies
the target directly, without setting that request. Thus a Z-only decrease
can change stored Z while leaving the previous mesh unchanged for this call.
An X/Y request can still cause a morph in that same situation.

Scale smoothing
With S=work+30 and V=entity+d4, original separately rounded operations are:
  displacement = S - 1
  damping = V * raw 3e199999 (approximately .15)
  restoring = displacement * raw 3e8f5c28 (approximately .28)
  delta = -damping - restoring
  Vnext = V + delta; Snext = S + Vnext
The helper stores Vnext at entity+d4, Snext at work+30 and 2-Snext at work+2c.
These are original per-call operations. No frame-rate independence, fixed-time
simulation or 60/120/240-FPS gameplay behavior is claimed by this checkpoint.
