Build artifact and reproduction

jp_native_asset_loading_support.lib contains exactly four authored production
members: textures_move.obj, assets.obj, memory_pvm.obj and bitmap_source.obj.
Their bytes match the audited objects. It REPLACES the overlapping older
PVM/bitmap upload support libraries. Link only one texture owner, memory owner,
frame owner, queue owner and video/device owner.

The library leaves the PRS codec as an external dependency. Compile the unchanged
public third_party/prskit/prskit.c separately and preserve its MIT LICENSE.txt.
Original game texture-wrapper and SDK metadata/helper objects must also be built
separately from the pinned external source. Game/SDK objects and diagnostic DLLs
are not members of this authored support library and remain private. No retail
content is embedded. The library is an incomplete research component, not a game.

Use the prerequisite workflow in JP_NATIVE_ASSET_LOADING.txt, then fresh private
output paths. The original-logo probe builder needs the matching WSL generated
progress/demo metadata from the preserved Japanese baseline:
