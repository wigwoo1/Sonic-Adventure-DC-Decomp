What the routine does
It walks 24-byte primitive descriptors, selects a 20-byte material record,
applies renderer material overrides, configures texture/colour/header state,
then calls the appropriate original primitive emitter. The near-plane count
selects ordinary or clipping-aware emitters. The textured clipped emitter can
tail-transfer to the environment-coordinate emitter. Actual native children
execute throughout; there are no fabricated service return values.

Two details matter for faithful behavior:
Material overrides affect the header setup word, while primitive selection
reloads the unmodified material word. Forcing texture flags therefore does not
necessarily select the textured primitive emitter. The independent routing
formula was corrected after the original/native comparisons exposed this test
assumption; the native game C already matched the original instructions.
The descriptor's top two bits index the original strip table [3,4,0,0]. Fixed
triangle/quad streams omit a count word; zero table entries read lengths from
the index stream. Tests preserve each real layout and the 24-byte loop stride.
