Original behavior retained
The SDK root global at 8c67c1d0 points to queue fields: buffer+194, capacity+198,
tail+19c, head+1a0 and count+1a4 (hex offsets). Entries are pairs of four-byte
words. Enqueue uses the original signed count/capacity comparison, writes both
words, increments the tail, wraps only on exact equality with capacity and
increments count modulo 2^32. Dequeue has no empty check: it copies the selected
pair to the two outputs in order, clears both entry words, advances/wraps head
and decrements count modulo 2^32. Empty-count underflow and unusual invalid
indices are preserved as actual caller-precondition behavior. Output aliasing
tests retain sequential effects. Root rereads, stack writes, original interrupt
mask restoration and error-log writes are executed rather than substituted.

Descriptor setup masks original source/destination and size arguments, writes
the low direction bit, callback and callback argument, clears its +30 field,
and retains untouched storage. Flag updates deliberately retain the original
odd behavior: first false branch clears bit1, second false branch clears bit0;
the final flags are limited to bits0..2. Nine arguments include five caller-
stack words. This leaf returns zero by its actual original instructions.
