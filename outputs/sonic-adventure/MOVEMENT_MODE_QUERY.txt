Recovered behavior and ABI
The original instruction at 049a4e reads a pointer from literal slot 049ae8
into R3. The original literal points to global 8c7492ac. It reads that word,
sets T when the word is zero, copies T to R0, and XORs R0 with 1 in the return
delay slot. Result: R0 is 1 for any nonzero raw word, otherwise 0. R3 retains
the literal pointer. Other registers, stack, RAM and FPU state are unchanged.
This is an integer bitwise query; floating negative-zero bits count as nonzero.
Memory addresses and offsets in this guide use hexadecimal.

The original two-argument standalone implementation, library and 128-case proof
remain preserved. The new combined DLL exposes the canonical symbol through
the current stage ABI and dispatches it through its connected entrypoints.
The old standalone ABI remains in the old standalone DLL. Do not call the new
stage export with the old two-argument prototype.

The current adapter uses the established original-instruction translator and
memory/device access layer. It preserves device reads and reached invalid-read
stops, including the pointer already loaded into R3 before a failed target read.
No SDK or SARecomp implementation code was imported.
