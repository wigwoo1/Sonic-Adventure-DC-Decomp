What changed
The actual shared sound SDK/game module now includes all25 original sdPstm
PCM-port functions and11 original MIDI status readers from upstream pin

Original port allocation, channel routing, base volume, rate-table play,

stream owner or RNA music scheduler.

Native adaptations and provenance
- Driver status addresses remain32-bit sound-RAM offsets. Explicit offsetof
  arithmetic replaces pointer-shaped calculations that truncate host pointers.
  Port pointers retain64 bits; stream records remain44 bytes and the wire
  status/channel layouts retain their original sizes.
- The original byte-before-varargs OpenPort entry uses the Win64 compiler's
  native variable-argument builtin. A diagnostic exception is confined to this
  entry. Actual mono/stereo calls, channel arguments, allocation and pointers
  are checked against the Japanese instructions' different calling convention.
  This qualification is for Windows, not a claim of Android/3DS ABI support.
- Signed integer wrap is defined for the generated SDK translation unit.
- Upstream GCC's two repairs are selected: mono right-pan uses an initialized
  channel value, and StopAll stops at the four actual PCM ports. These are
  explicitly tested native extensions; the original undefined stack value and
  out-of-bounds StopAll writes are not presented as equivalent behavior.
- An unreferenced four-byte matching-data object required by the MIDI source
  is extracted locally from the supplied, SHA256-checked Japanese binary.
  The bytes and all combined SDK/game binaries remain private. Reproduction
  keeps the complete original source as a pinned external dependency.

How to check
Open analysis/jp_native_pstm_package.json and its exact source/proof hashes.
To reproduce, supply the pinned upstream source, prior qualified streaming-
decoder baseline, Japanese1ST_READ.BIN, track03.bin and local compiler/runtime.
Run jp_port_tools/build_native_pstm.py --help for its required local paths,
then verify_native_pstm.py --help and use new output directories. The package
also identifies all current regression commands, reports and limitations.
Original retail binaries, extracted data, firmware RAM/PCM captures, toolchain
bundles and credentials are excluded from public source and releases.
