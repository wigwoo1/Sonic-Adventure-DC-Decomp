Behavior

leaves both optional outputs untouched and executes no floating-point instruction.
Otherwise, the routine reads the actor's indexed table value. A nonzero value
is accepted when flag 2000 is set or the character-state word is zero. If accepted,
it writes the raw heading and value to the non-null output pointers, in that order.
A zero value takes a fallback: actor mode must be zero, flag 100 must be set,
and the actual stage query must return 0902 or 0903. This copies actor heading
and zero to the optional outputs. Other cases return zero without output writes.

The second value load is live. A first output that changes the table value or
actor index affects the later read. Tests cover these aliases, shared outputs,
and writes back to actor heading. Signed stage words are passed through the
original 04F7E0 code; no stage result or execution frame is supplied.
