placement task level. After that level returns, the stage runs the
original sphere worker over the registered rings and drains the list.

freed. The stage still supplies a world-space player sphere snapshot.

build, then run verify_native_emerald_projection_profile.py with the
new build and the same local geometry, character and disc inputs.
