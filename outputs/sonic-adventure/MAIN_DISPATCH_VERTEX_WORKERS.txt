Behavior
The workers transform the input positions, compute perspective coordinates and
reciprocal absolute depth, write vertex-record words, and optionally copy three
normal words. Classification variants build six clip bits and publish combined
AND/OR masks through the record. Depth below the near limit follows the original
non-projection path. Both normal and no-normal streams are supported.
Each iteration consumes a vertex and preloads the next position, including a
lookahead beyond the last processed vertex; test buffers preserve that padding.
The recovered instruction order, delay slots, FPU bank/width handling and reached
numeric guards remain explicit. This is static C, with no runtime opcode decoding.

Portable native memory interface
  source/vertex_bus.h
  source/vertex_bus.c
Workers keep RAM accesses direct and route non-RAM accesses plus OCBI/PREF through
a supplied bus. The connected DLL's exported functions take a final bus pointer;
older DLL interfaces and their reports remain unchanged. sa_vertex_bus_init
initializes queue/register/counter state and binds RAM plus native callbacks.
The C backend models two store queues, their address-control registers and
MMU-off transfers into coherent RAM. Cache invalidation and ordinary prefetch
are logged rather than timing-emulated. The diagnostic trace retains 4,096
events and counts later dropped entries; filling the trace never stops processing.
This adapter is authored support code and receives no original-routine credit.

Hardware reference used for the bounded model
Renesas SH7750/SH7750S/SH7750R Hardware Manual, section 4.7.1-4.7.3,
printed pages 142-144:
https://www.renesas.com/en/document/mah/sh7750-sh7750s-sh7750r-group-users-manual-hardware
The manual defines queue selection by address bit 5, word placement in the queue,
and aligned 32-byte transfers from PREF using queue address-control registers.
The tests compare the C model with a separately written Python implementation.
This establishes the stated software contract, not hardware timing or GPU fidelity.
