Observed behavior
R4/R5/R6 identify three cached vertices; R7 identifies six signed 16-bit UV words.
Active FR4 supplies the face lighting factor; the helper does not calculate it.
It reconstructs camera coordinates where required, clips against the near plane
and interpolates signed integer UVs using the original FMAC/FTRC sequence before
scaling them by 1/256. Input UV words and the input vertex cache remain unchanged.
The helper uses UV scratch 8c890268, camera scratch 8c890278 and orientation
8c8902fc. Input UVs from the connected parent are staged at 8c890304.

Output packets contain control, projected x/y/reciprocal depth, U/V, lighting
factor and a retained final word. The first two vertices retain the selected
queue's prior factor word; the third and, for quadrilaterals, fourth receive the
supplied FR4 factor. The final word remains untouched. Quadrilaterals emit in
strip order 0,1,3,2. No normalizer call, factor-cache write or game call occurs.
