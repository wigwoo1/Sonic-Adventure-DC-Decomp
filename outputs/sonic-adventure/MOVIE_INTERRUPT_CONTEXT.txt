Original normal context 0x8c65e80c preserves integer registers, both floating-point
banks, FPUL/FPSCR and saved processor state, calls the live VBR event handler,
then executes its original RTE and delay slot. Original nested context 0x8c65e958

entry. Independent canonical physical-bank assertions check the complete
interrupted state after return. Native RTE propagates an internal unwind status
through existing native calls; no guest R0, PR, helper return or completion is
invented. The separate exception API leaves historical structure layouts and
entry APIs intact; six representative old-ABI comparisons pass.

Two copied vector templates 0x8c65e7a4 and 0x8c65e7d8 have 20 code rows each, followed by
literal data and saved-R0/handler fields. They are fragments, not additional
recovered routines. Relocated VBR+0x100/+0x400/+0x600 aliases receive zero duplicate
credit. Original 0x8c645de0 really copies the templates and chooses the normal or
nested handler in the lifecycle tests; no resumed guest checkpoint is used.

support, not retail-code comparison or recovery credit.

https://www.renesas.com/en/document/mas/sh-4-software-manual
SH-4 software manual rev 6, special-register transfer and RTE descriptions.
RTE restores saved SR and branches after a delay slot; SSR transfers retain the
full saved word. Restored bank selection is checked independently of native
array swapping. Existing original RTE delay slots here are NOP instructions.

SH7750 group hardware manual rev 7.02, exception handling. The declared ordinary
IRQ input respects BL, IMASK and delay-slot exclusion and captures saved state.
The host does not claim electrical timing or automatic acceptance.
