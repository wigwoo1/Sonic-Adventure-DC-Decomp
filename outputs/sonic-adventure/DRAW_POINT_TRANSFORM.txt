What changed
The original point-transform helper at 8c638ecc..8c638f24 now has a complete
guarded native source in source/sa_draw_point.c. Its 44 instructions / 88 bytes
are checked against 1ST_READ.BIN. It is a distinct first registry entry with
integration verification; descriptive names remain inferred.

The helper transforms a position using either a supplied matrix (three FIPR
operations) or the current matrix bank (FTRV). Its homogeneous input W is one,
so translation applies. It stores XYZ without perspective division. The implicit
path also retains the computed fourth component in the FPU bank. Explicit and
implicit paths retain their different output-pointer results.

Instruction order matters when buffers overlap. The explicit path reads the
second matrix row before storing X, then reads the third row before storing Y.
The implicit path computes the complete vector before its reverse-order stores.
The new source preserves these orders, dynamic FMOV bank/width, reached guards,
partial writes, numerical status and return-delay-slot behavior.

The earlier source/model_point_transform.c and its injected-vector proof remain
available. That experiment checked orchestration with supplied vector outputs;
the new connection uses the real pinned numerical backend and receives no
duplicate recovery credit for the old experiment or reused renderer services.
