Observed behavior
The material loop selects this pair for layouts 2600000 or 3600000 hex, with
secondary-header selection handled separately. UVs are generated from each cached
normal and the matrix published through 8c890238. In ordinary single precision:
  U = 0.5 + 0.5 * dot(normal, matrix column 0)
  V = 0.5 + 0.5 * dot(normal, matrix column 1)
The original multiply/FMAC order is retained; segment UV tables are not used.

lighting normalizer executes. Packets contain control, projected x/y/reciprocal
depth, U/V, factor 1.0 and an untouched final word. Direct input caches remain
unchanged. Triangle, quad and strip loops retain original winding/rejection,
counters and cursor effects.
