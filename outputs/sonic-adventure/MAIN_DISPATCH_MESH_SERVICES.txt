Behavior
The filter optionally tests a transformed bounding sphere against depth and
projected screen limits, prepares a transformed/normalized normal vector,
publishes work counters, and calls one of four vertex/filter workers. Its seven
indirect jumps retain internal acceptance/rejection flow. Native scalar divide,
multiply-add and the existing vector backend are connected at reached operations.
The material-flags helper updates selected header bits with two masks. Shader
setup combines material/environment flags, updates three header words, and
publishes the argument through a destination pointer. Texture setup follows
the table/descriptor chain, caches two descriptor words, updates texture fields
and checks an address field. A failed address check returns guest R0=-1 after
its preceding cache/header effects; host execution can still complete normally.
Command finalization combines the low 26 argument bits with a global word and
writes the result through the command destination pointer. It is not a heap
free routine; earlier reports used a release-service substitute at this boundary.

Renderer-state terminology correction
The earlier routines named render_state_save/restore transfer nine state words
between renderer structures and the working header. Real material services
intentionally change that header. The final transfer therefore publishes the
updated state rather than invariably restoring the pre-draw values. Earlier
preservation assertions were valid only for their stated substitute behavior.
The connected lifetime test now independently checks the actual nine-word
transfer/mapping after a draw, and unchanged renderer words on an idle pass.
Recovered game instructions and the older immutable proof reports are preserved.

Reached adapter guards
Constructed SZ=1 inputs can overwrite the filter's saved mesh pointer or return
address through the original wide-FMOV stack layout. Instead of following an
unsupported address, the native adapter returns host -3 at a reached boundary:
  8c6114f8, 8c6115a6, 8c61162e: saved-pointer dereference outside modeled RAM;
  8c6116e4: changed return address, before its RTS delay-slot instruction.
The reference stops at the same boundary and compares partial state. This is
an explicit adapter limit, not physical Dreamcast memory-fault/exception emulation.
Normal single-width execution remains unchanged. These guards are recorded in
the translation manifest and registry; there are 24 such cases in the final suite.
