What changed
The entire original sdk/sofdec/adx_stms.c now links into the existing native
sound module, with28 original stream exports. Original GDFS requests refill
caller-owned ring joints repeatedly rather than requiring a preloaded song
prefix. The original SJD/ADXB/ADXPD decoder and RNA/SDK/AICA path consume them.
This uses the existing System, filesystem, sound lock, frame clock and audio
worker. No second reader owner, clock, shadow file pool or output client exists.

jp_adxstm_initialize/service/shutdown/snapshot enforce the creating sound thread
and existing sound lifecycle. Active streams are serviced automatically by that
owner's SDK/elapsed-time path. Global sound shutdown cancels and closes actual
file requests before RNA, G2 or the borrowed System filesystem is disposed.
Caller-owned input joints/buffers remain alive until successful retirement.
Stop the caller's decoder first: original ADXSTM_Stop resets its input joint.
Full ADXT ownership of those decoder/joint lifetimes is still a later step.

Native adaptations and provenance
Original source pin:25a3d3154dbe657325e97dbe8c5291086f6af5c0.

  result before writing through it, and close the real file/range on failure.
