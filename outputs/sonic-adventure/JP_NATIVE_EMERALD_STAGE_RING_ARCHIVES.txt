Native disc-backed Emerald Coast ring textures

The native stage read queue fetches OBJ_REGULAR.PRS and EFF_REGULAR.PRS
from the local Japanese disc. The stage resource owner decodes both and
the ring texture loader selects the original ring entry and eight
sparkle entries for the stage-owned texture lists.

Build with build_native_emerald_stage_ring_archives.py using the
verified stage ring texture build. Run
verify_native_emerald_stage_ring_archives.py with the same local
disc, geometry and scene inputs as the previous ring texture check.
The Windows build compiled and linked, passed 600 scene checks and
reproduced both previous captures byte for byte.

The fixture still supplies model geometry and sprite animation from
the local executable. The full native frame draw remains integration
work. Whole-project completion is about 10%.
