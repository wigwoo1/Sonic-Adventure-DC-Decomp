Predicate dataflow
Global 8c754ec8 nonzero returns R0=0 before any floating-point operation.
Otherwise FR7 is retained as a radius-like input, FR7 becomes 1.0 and FTRV
transforms FR4..FR7 with the opposite-bank matrix. Reached depth and projected
coordinate tests return R0=0 or 1. Original comparisons are strict > tests.

For ordinary narrow finite inputs, define transformed x,y,z, radius r,
N=*(8c88f610), F=*(8c88f614), P=*(8c88f5e4), Ox=*(8c88f5f0),
Oy=*(8c88f5f4), Sx=*(8c88f618), Sy=*(8c88f61c), and four bounds B0..B3
at 8c88f600. Every arithmetic operation retains its separate original rounding.
Require z>N-r and z<=F+r. Set inv=1/(z+r), Gx=(Sx*P)*inv.
Require (x+r)*Gx+Ox>B0 and (x-r)*Gx+Ox<=B2.
Set Gy=(Sy*Ox)*inv. Require (y+r)*Gy+Oy>B1.
The final test requires (y-r)*Gx+Oy<=B2: it reuses horizontal Gx and B2.
B3 is read but never used in a comparison. This unusual original behavior
is preserved and independently checked, not repaired based on guessed intent.

Four-float state
The wrapper saves PR, reserves 16 stack bytes and stores active FR4..FR7 at
four consecutive offsets. It passes that address to the original copy routine,
which transfers four raw fields to global 8c88f668..8c88f674. Reads and writes
remain sequential, preserving overlap effects. These are raw FMOV fields,
not arithmetic conversions or inferred colour clamping.
PR and SZ select the original raw-bank/width behavior. With wide stores, the
last stack store can overwrite the saved return address. The reached return
guard retains that original partial state instead of inventing a valid return.
