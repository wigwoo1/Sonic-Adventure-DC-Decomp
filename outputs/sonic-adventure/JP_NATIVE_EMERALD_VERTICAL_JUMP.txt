Native Sonic vertical jump and landing

The native jump step applies vertical gravity and drag and checks for a
descending crossing of the static stage floor. The landing restores the
grounded standing state and selects a landing action from impact speed.

Build with build_native_emerald_vertical_jump.py using the verified
ground-jump build. Run verify_native_emerald_vertical_jump.py with the
same local disc, collision and character inputs. The Windows build
compiled, linked and passed 600 scene checks. After the retained pickup
frame, the probe checks upward and downward movement, airborne flags,
and return to the same floor at rest. The captures precede the jump.

This path covers a neutral vertical jump. Live dispatch, horizontal
steering, jump hold, animation playback and other collision are still
integration work. Overall project completion is about 10%.
