Two original straight-line helpers have been recovered as native static C:
8c60a1f6 - two three-component binary32 vectors, 27 instructions, end 8c60a22c.
8c60a250 - two signed 32-bit integer-angle triplets, 40 instructions, end 8c60a2a0.
Names and roles are inferred from the original instructions and observed callers.
Both take the interpolation weight in the active bank's FR4, source in R4 and
output in R5. Each source contains a first triplet followed by a second triplet.
Neither body has conditional branches or calls to missing game services.

The code forms 1-t, rounds the first component's first product with FMUL, then
adds the weighted second value with FMAC. The remaining components round the
second product with FMUL, then add the weighted first value with FMAC. These
orders can produce different binary32 results and are preserved. Later loads
occur after earlier stores, so overlapping input/output buffers must retain the
original sequential behavior. The integer helper additionally uses signed FLOAT
conversion and FTRC truncation/range saturation; there is no shortest-arc angle
adjustment or additional angle normalization/clamping in this body.
