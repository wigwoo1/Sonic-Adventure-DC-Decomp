Original game debug-text family on the native renderer
Whole-project estimate: approximately 10%; goal active. No playable PC game yet.

What changed
All 13 original src/draw/text.c functions now compile into the existing native
frame module: style init/exit, size/colour setters, normal/front glyph routines,
string/front-string, decimal/binary/hex/fixed-float and variadic printing.
The function bodies remain a pinned external input, generated/adapted privately.
Public builder tools record original function hashes and boundary adaptations.
The unchanged original init reads the actual font header from DEBUG_CONTEXT 4.
Drawing uses the real existing direct translucent queue, font/resource owner
and original SHC formatter already adapted to native varargs and bounded I/O.
There is no second font allocator, queue, formatter or rendering-only fake state.

Native boundaries
SH-4 store-queue/QACR addresses and pointer truncation become a bounded staging
transaction through the existing print transport. Original glyph geometry and
formatting bodies still write the packets. Coordinate products use the qualified
RZ/int16 wrapping helper; pen advances preserve original signed-word wrapping.
All glyph arithmetic is within exactly representable dyadic/integer ranges and
the resulting defined packet words match the original machine instructions.
Padding words undefined by the console source are deterministically zero.
The original signed-character behavior, italic geometry, 0-to-O substitution,
foreground depth, size/colour state and frame_step suppression are preserved.
Suppressed calls skip argument access, including invalid pointers/formats.
Invalid native lengths/digit shifts and original fixed-float buffer-underwrite
domains are rejected by existing checked boundaries instead of corrupting memory.

Verification
32,220 packet/state/format assertions passed across 438 complete original entry
calls. All 13 original bodies and original formatter dependencies execute in the
qualified SH-4 reference; no original game/format function is hooked. All 255
non-NUL character byte values, normal/front geometry, zero/large sizes, signed
coordinate wrap, integers, floats and mixed native varargs are covered.
24 additional checks prove exact game/SDK/game packet concatenation, independent
style state, formatting rejection, suppression and recovery through one owner.
16 GPU/window/lifetime assertions independently verify 327,680 textured/Texture
Off pixels and an actual 163,840-pixel native backbuffer. Texture Off renders
vertex-coloured quads with zero texture and sampler bindings. A submitted frame
survives the actual SDK font release; the final frame release frees its payload.
591 original Japanese save-default/layout/CRC assertions pass on the new build.
7,726 original startup/logo/EOR/exit checks pass with six actual vertex-buffer,
original default-font and game style initialization sequences, 570 GPU frames
and Presents and independent comparison of 175,104,000 logo pixels.
Total: 40,577 assertions; 573 GPU images. Compile/link passed with warnings as
errors. Every pre-existing production frame object remains byte-identical.

The startup oracle now expects only the actual SDK font after logo textures are
released. The previous logo-only caller initialized no font and expected zero
surfaces at that point. The system-exit oracle still requires zero surfaces and
all native owners drained. This adapts the Python caller/expected state, not
native function bodies. Context initialization also installs a white background;
the text scene explicitly selects black before its independent pixel comparison.
