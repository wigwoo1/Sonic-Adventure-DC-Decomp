Finding and platform profile
The callback at 8c6734c4 initially contains 8c000000. The original driver reads
system-bus register a05f689c, takes its low byte and compares it with ten. Values
below ten execute the legacy fallback; ten or higher take the original return
path. No callback target, return value or game instruction has been rewritten.

The pinned Flycast implementation identifies 005f689c as SB_SBREV (system-bus
revision) and initializes it to hexadecimal B (decimal eleven). This milestone
uses eleven as an explicit raw platform observation. It does not change the
old backend default, measure the user's console or guarantee every hardware
revision. Revision zero/nine controls still reach the genuine unknown callback.
The original slot remains 8c000000 before and after all fifty comparisons.
