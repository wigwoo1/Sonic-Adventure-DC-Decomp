The settings query clears its output, reads the settings packet, and applies
the original signed-byte fallback and character conversion. Global 8c67340c
contains a buffer pointer, not a boolean: the original caller passes that value
implicitly in R5 to the existing flash/settings reader. Tests use real original
helpers, including real flash format, erase, read and error paths.
