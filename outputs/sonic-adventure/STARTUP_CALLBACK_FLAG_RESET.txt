Startup callback flag reset at 0x8c107aaa
========================================

Correction (2026-10-24): the original native source used the wrong callback
return PC, 8c107ab8. It now supplies 8c107aba, matching the original JSR. The
test compares actual callback-entry registers/SR/PR and rejects the preserved
old DLL. See BOOT_SETUP.txt and analysis/startup_callback_flag_reset_regression.json.

The 14-instruction helper reads its flag address from the executable literal at
0x8c107b80 and reads the flag from that address. A zero flag skips the indirect
callback. A nonzero flag calls the target loaded from 0x8c107b84 with the flag
value in R4, then stores zero through the flag pointer. In both branches it
restores PR and the stack before returning.
