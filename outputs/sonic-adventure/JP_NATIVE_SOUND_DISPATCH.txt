Native frame sound dispatch and whole game sound-module audit
Qualified 2026-11-05. Overall approximately 10%; goal active.

What changed
The original compiled frame_vsync and frame_wait_step now reach an owner-bound
sound dispatcher. Their former diagnostic sdSysServer/sound_send_queue functions
record their passive trace event and forward to actual registered callbacks.
An unbound SDK service returns SDE_ERR_NO_INIT; an absent game request producer
is explicitly unavailable. It no longer reports successful diagnostic sound work.
The genuine original frame bodies and all graphics providers are preserved.

The authored dispatcher lives in the same private presenter module as those
frame functions. It borrows callbacks/context from the creating sound owner;
it does not create another SDK, emulator, clock or game state. One binding has
a nonrecycled token. A live callback cannot replace, recursively dispatch or
retire its own binding. Foreign-thread operations fail without touching outputs.
After unbind, real later vertical ticks cannot call the retired SDK/context.
Callback failures propagate to the SDK-facing result and observable native state.

Verification: 7,970 checks
- 98 checks in two fresh processes test token/context lifetime, reentrancy,
  replacement, foreign-thread rejection, optional queue availability and actual
  frame -> SDK execution. The integrated case starts the real compiled system
  owner, reads MASARU.DRV and EMERALDCOAST.MLT through original GDFS into guarded,
  sector-rounded aligned buffers, executes both original driver initializations,
  then downloads the bank through the actual SDK.
- Real clock/vblank delivery runs original frame_wait_step/frame_vsync. A test
  request client invokes original SDK MIDI/stereo/effect producers, and the bound
  server performs real copies/completions. All 88,200 note frames, 44,100 tail
  frames and final 2 MiB RAM match the independently qualified driver reference.
  No manually cleared status byte or invented driver acknowledgement is used.
- 591 save regressions include 29 complete unhooked Japanese instruction calls.
  The prerequisite proof was rerun against this exact new build manifest; an
  initial attempt correctly rejected the older build's differently bound proof.
- 7,281 reset/boot/logo/exit regressions pass with the new presenter. Six compiled
  system starts, 570 real GPU images/Presents and 175,104,000 compared pixels
  retain the previous behavior. The fresh actual SEGA backbuffer capture has
  SHA256 9b28f7b43d8786cfee116fc34b39ed33ff44fb8ed93a0f62b21477b4902d2071.
  These graphics cases exercise the unbound sound boundary; the separate sound
  case exercises bound SDK dispatch. They are not a full-game audiovisual test.

The two trace-facing functions are now exported as forwarding interfaces. The
first client test found they were previously internal; its evidence is retained.
The initial builder also encountered a compact one-line fixture definition that
the multiline function extractor could not parse. The replacement now verifies
the exact original line before changing it. All previous versions remain local.
The authored helper and adapted presenter compile/link without diagnostics.

Whole game sound source audit
The entire pinned src/sound/sound.c now compiles privately, rather than only a
handwritten initializer. Console SDK declarations are parsed before selecting
the original GCC game guards, including repaired success returns. Native sound
identity fields, API id parameters and the task-pointer cast use intptr_t;
other game scalars remain 32-bit. All native callers must use the same private
header overlay. This compile-only adaptation is not a runtime ID/numerics proof.

The object has 62 external references. A name-level provider inventory finds
23 absent providers. The actual complete link fails on 27 symbols: four existing
data exports additionally require proper native DLL import declarations. These
different counts describe different questions. Settings, stage/spatial helpers,
QSound and stream requests remain real dependencies; no dummy providers are
added. The object and its fixed-address WORK_AREA paths are not executed. The
three settings imports on initialization are syCfgInit, syCfgGetSoundMode and
syCfgExit; port them to real native configuration before running that path.
