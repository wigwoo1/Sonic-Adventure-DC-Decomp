Two shipped face-strip occurrences
AL_MAIN.BIN contains model 8ca50cbc / object 8ca50ce4. AL_RACE.BIN contains model
8cbcad80 / object 8cbcada8. Both have fifteen vertices and two segment records:
eleven triangles followed by a five-index 8000 group. Original flags 9571a400
select environment-face lighting under default dispatch. The five indices are
3,4,7,5,6 after the count word 5. The two index streams have identical SHA256;
they are two stored occurrences, not two proven unique artworks.

This finding matters because the previous bounded main-executable scan found no
face-lit 8000 combinations. Absence in that image did not establish absence in
shipped data. The decoded overlays contain actual records with the combination.
Actual scene/camera reachability is still a separate unverified question.

The original near-crossing branch at 8c61ef72 is reached in 24 constructed-camera
cases using these unmodified records. It reads R12=the current segment,
R14=renderer state and R13=the material, not indexed cache normals. Reference and
native normalizer inputs match; their sums/classification are independently
checked. All 24 readings include a material word which is NaN when reinterpreted
as a float. Original behavior is preserved, with no invented colour/normal fallback.
This is not proof of hardware NaN payload precision or actual visible game output.

Newly recovered selector: AL_MAIN.BIN 0c905548
Source: source/sa_overlay_face_model_selector_0c905548.c
The complete body has 88 original instruction rows / 176 instruction bytes.
The contiguous span 0c905548..0c905618 is 208 bytes including its literal pool;
that larger span is not counted as instruction recovery. A read-only Ghidra
export was byte-checked against original AL_MAIN.BIN. Names are inferred.

R5 identifies an entity. The selector reads a byte through entity+ec, pointee+34,
and reads the destination object through entity+2d4. It initializes the object's
three scale fields at +20/+24/+28 to raw 3e999999 (approximately 0.3). Bits are
prioritized 10,08,04,02,01 hex. The highest set supported bit selects a source
object whose mesh pointer is copied to destination+4. With none set, the old
mesh pointer remains. Other flag bits do not select another model.
Bit 10 loads the pointer literal at 0c9055ec: physical object 0ca50ce4, whose
mesh is 0ca50cbc, matching the inventoried AL_MAIN face-strip model.

The full integer register/SR effects are retained, including the original RTS
delay-slot write. FMOV uses FR/SZ directly; PR does not gate these raw transfers.
Wide SZ stores retain the original overlapping writes and companion word
0ca50ce4 at destination+2c. These are tested original effects, not a recommended
normal runtime mode. This selector is verified separately from the mesh tests;
a complete selector-caller/object-transform/render pipeline is next work.
