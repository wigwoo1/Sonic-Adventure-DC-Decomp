Original behavior retained
The setup helper checks the supplied frame against the unsigned frame count,
including the original signed conversion, correction by 2^32, and two distinct
rounding operations. Rejected frames return before global setup or drawing.
It sets format/type/interpolation fields, frame, counters and callback slots.
Null motion preserves the earlier data/count fields while resetting the
selected type/format/interpolation fields. Unwritten upper halfwords survive.
Base and animated position/rotation/scale handlers are selected separately;
the root's rotation-order flag selects the two different rotation callbacks.
Renderer state save/restore uses the existing native original bodies.

The recursive driver preserves original matrix pushes/pops, optional node
callback invocation, mesh-skip flag handling, child recursion and sibling loop.
The format-zero handler calls position, rotation and scale in original order.
Base helpers retain original explicit-matrix versus FPU-matrix routing and
register/stack effects, using existing native transformations. The optional
callback checks use the real native RTS/NOP body at 8c611708 as supplied data.
This is neither an interpreter hook nor proof of natural callback creation.
