What changed

Seventeen genuine original texture lists and their arrays now live in the SAME
Frames module and use its existing texture/memory/PVM/PRS/file owners. They cover
all eight original texture character IDs: Sonic, Eggman, Tails, Knuckles, Tikal,
Amy, E-102 and Big. These are texture IDs; the checked motion selector separately
accepts only its six original playable-character choices. No second texture
registry or duplicate canonical motion/model data is introduced.

Twelve preserved source units supply 34 data definitions. Their 418 texture
entries, filename contents and initial scalar fields match the supplied Japanese
executable or actual TIKAL_PROG.PRS image, with full-width native pointers.
The original character_users table, per-character file/list tables and three
load/release/release-all C bodies are retained. Guards around real dependency
calls stop a failed load before the original logical-user increment.

One source array, e102hit_textures, is declared const but its original list casts
away const and the actual loader writes handles/attributes into it. Its native
copy uses writable storage with the same initial values. The original source is
unchanged. Other selected texture definitions are unchanged.

The checked owner validates character ranges before indexing, enforces the
creating thread and bounds the original signed-byte user count at127. A second
logical user shares the existing bindings without another file load. Only the
last normal release retires SDK references. release_all is an explicit operation
retiring ALL character users; caller tasks/draw submissions must already be done.
Shutdown requires users and partial work to have retired. The APIs borrow real
initialized texture/video/memory and asset providers and do not close them.

A missing second Sonic file and a real insufficient texture table both retain
actual partial bindings/pending PVM references. Clear the reported native error,
then recover explicitly; references are not silently abandoned. The repaired
condition can then be retried. Foreign-thread and invalid-character/output calls
reject without changing ownership or caller output.

This owner must be closed BEFORE its borrowed providers/System are retired.
Automatic System/Exit character-texture authority is not yet implemented. The
full-parent test explicitly closes character users and their borrowed asset
provider before releasing real model/action motion views and letting System close.
Future texture/task/render consumers must maintain those real lifetime contracts.
Exported raw definitions are diagnostics/shared-module data, not a bypass for
unchecked mutation. Output buffers must be valid, writable and disjoint from
owned storage. Keep the DLL and borrowed providers alive until users close.

Rendering found the earlier decoder's explicitly deferred VQ1x1 mip gate. A
new authored extension includes the frozen decoder unchanged and delegates every
previously supported path to it. Only the smallest VQ mip adds new behavior:
2049 encoded bytes are required, with byte2048 selecting a codebook vector and
its bottom-right (texel3) colour supplying the1x1 value.

Primary implementation reference, pinned for reproducibility:
https://github.com/flyinghead/flycast/blob/7adbf3caef251b153e348df3f469a0f35878339d/core/rend/TexCache.cpp#L535
The VQMipPoint table and both mip conversion branches establish this format
contract. No Flycast code is included in production. The primary source's full
bytes remain a private reference with a recorded SHA256. This is source-backed
format verification, not a claim of comparison with captured Dreamcast pixels.

The original SDK first reuses an already listed globalIndex before parsing a
later payload. Real E-102 files exercise that rule: E102HIT entries can share an
earlier effects texture even when the later archive's dimensions differ. The
pixel oracle independently derives the effective first-loaded image from real
file/chunk order. It does not replace these aliases with different textures.

Build and verification

Sixteen compile/link commands passed with warnings as errors and zero diagnostics.
A GNU-quoted response file preserves the exact expanded link arguments beyond
Windows' command-length limit. Existing Frame objects and four earlier GPU
objects are retained; only the authored decoder object is replaced in GPU.
Twenty-two other DLLs, the motion selector/data/owner and all prior proof hashes
remain unchanged. Actual PE imports remain acyclic; GPU exports are preserved;
unchecked original/private helper entry points are not exported.

8,199 character checks cover original definitions, all eight real file loads,
logical sharing, signed overflow, simultaneous characters, release-all, genuine
partial-load recovery, foreign callers and ordinary restart.

3,049 graphics checks render all418 actual list entries through retained native
frames and D3D, comparing711,168 native-size pixels with an independent raw-PVM
oracle. Observed formats include twiddled RGB1555/565/4444, original mip chains,
VQ, mipmapped VQ and linear textures. Comparisons use opaque point filtering,
neutral mip bias and the largest level. Full original mip chains are uploaded;
these tests do not establish every filtering/alpha/LOD or hardware behavior.

5,860 checks after removing only the obsolete VQ1-UNSUPPORTED expectation.
