Original RNA/mwSnd native audio middleware (2026-11-05 local)

Status: VERIFIED for the scoped middleware tests below. Retail file streaming
and the playable PC port remain unfinished. Overall project estimate remains
approximately 10% of weighted milestones; the goal stays active.

What changed
The actual native sound owner now links five complete, pinned upstream modules:
mw_sdbuf.c, mw_rnaer.c, mw_sdcs.c, mw_rna.c and adx_rnas.c. Their 116 middleware
exports are available in the private combined SDK/game build. This export count
does not mean 116 individually matched or newly decompiled game routines.
Original Japanese source pin: 25a3d3154dbe657325e97dbe8c5291086f6af5c0.

RNA's original chunk borrowing, sound buffers, PCM ports, transfer completion,
playback and sample-position polling use the existing SDK/G2/AICA graph. Once
initialized, RNA runs automatically in the existing native sound-clock service.
There is one existing Windows output client. The audio worker does not execute
game code. syTmrGetCount samples the shared 781250Hz native clock, retaining
32-bit wrap behavior and exposing failed/backwards clock sources explicitly.

Native ownership prevents service or teardown from foreign threads and rejects
reentrant shutdown from middleware error callbacks. Shutdown first stops further
input borrowing, drains actual queued DMA callbacks, stops/destroys the original
renderers, drains final stop/reset commands, and retires the borrowed error
callback. The underlying SDK, G2, firmware and output remain alive until then.
An outer callback gate blocks cleanup while preserving the live resources for
retry. Caller-owned joints and their buffers must outlive every renderer using
them; the future ADXT owner still needs to enforce this across file streaming.

Native adaptations and preserved evidence
- A failed mwSndOpenPort allocation now frees buf[j] in its rollback loop.
  The original used buf[i] after that loop's counter reached the channel count,
  leaving the allocated buffer live and potentially selecting an invalid slot.
- Both original RNA silence arrays are explicitly aligned to 32 bytes. A native
  compiler otherwise placed them at 16-byte boundaries, which the real DMA
  adapter correctly rejected during silence flushing. DMA validation remains.
- Native pointers retain their full width. Existing compiler/GCC compatibility
  repairs and the real G2 callback gate remain in use. Generated source records
  identify the exact original modules and authored transformations.
- Four genuine private data includes are regenerated with upstream data.py
  --bodies from the supplied, hash-checked Japanese binary and preserved matching
  listings/dependencies. They match the prior matching build byte for byte.
  Placeholder --texts output is not used. Original listings, generated includes,
  failed-attempt diagnostics and earlier source/proof hashes remain preserved.
- The test fixture reads the actual 32-bit middleware port-count fields at their
  correct width and explicitly selects CPU or DMA transfer mode. The bootstrap
  defaults to DMA; naming a test CPU alone would not select that mode.
