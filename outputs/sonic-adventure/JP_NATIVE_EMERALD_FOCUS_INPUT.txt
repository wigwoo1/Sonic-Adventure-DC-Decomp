Foreground input gate on the Emerald Coast window

The verifier requests foreground activation for the render window,
then compares native input focus against the Windows foreground HWND
before and after each stock input poll. The OS declined the activation
request. All four polls saw stable foreground ownership elsewhere
and the native provider reported the window as unfocused.
