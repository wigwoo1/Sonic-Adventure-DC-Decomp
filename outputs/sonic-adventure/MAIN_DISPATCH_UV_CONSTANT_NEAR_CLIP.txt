Observed behavior
R4/R5/R6 identify three cached vertices; R7 identifies six signed 16-bit UV words.
The helper reconstructs camera coordinates where required, performs orientation
rejection and clips against the near plane. UV edges use the original FMAC/FTRC
sequence, truncating to integers and storing/re-reading signed low-16-bit values
before scaling by 1/256. Input UV words and input vertex cache remain unchanged.
UV scratch is 8c890268, geometry scratch 8c890278 and orientation state 8c8902fc.
The connected parent's input UVs are staged at 8c890304.

Output packets contain control, projected x/y/reciprocal depth, U/V, factor 1.0
and an untouched final word. Every emitted vertex gets factor 1.0, including the
first two. The helper sets that constant internally; it does not accept the face
factor used by the earlier UV-face clipper. Four-vertex results emit in strip
order 0,1,3,2. The final packet carries control f0000000. No game calls occur.
