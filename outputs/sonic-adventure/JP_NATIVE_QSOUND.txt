What changed
The pinned Japanese SDK sdQsndSetPos now runs unchanged in the same actual
Sound SDK/owner used by the qualified timed audio graph. Four original game
functions are linked alongside it: sound_set_qsound, qsound_range, qsound_alloc
and qsound_free. There is one original sound-slot table and one QSound owner
table, rather than a second isolated imitation of the game state.

The game wrapper is privately renamed and captures the actual SDK result that
the original void wrapper ignored. The typed native entry jp_sound_set_qsound
requires the existing ready creator-thread sound owner, reads exactly seven
bytes, retains no caller pointer and preserves every position byte's original
bits. A full secondary queue returns JP_SOUND_QUEUE (15) without quarantining
the healthy owner. Invalid input, foreign access and calls after shutdown keep
the established owner rules. There is no host-side position clamping.

The copy-owner table stores uintptr_t on PC. Original ID+1 encoding uses
unsigned native-width addition, preserving high pointer/ID bits and making
wraparound defined. Supported-effect lookup, channel/copy selection and free
behavior otherwise follow the original source. Original ID -1 still encodes
the zero/free sentinel; that historical ambiguity is explicitly preserved.
This does not qualify all other identity uses in the full sound module.
