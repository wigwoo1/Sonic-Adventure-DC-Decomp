The new API adds an explicit caller-owned native disc queue and firmware-vector

This deliberately reuses declared host policies: one MODE1 sector per pump,
queued request handles, terminal handle consumption, read-only drive status,
native platform identity, cancellation and generic host I/O error reporting.
These policies are not a decompilation of Dreamcast firmware, cache hardware or
physical drive timing. Actual transport offsets and every read attempt, complete

Pointers in queue snapshots are compared as guest offsets; callback identities
are independently configured transport inputs, not purported firmware state.
