Explicit native hardware interface
source/hardware_transfer_bus.c/h wraps the previous display/A/V/cache interface.
It accepts borrowed raw 32-bit FIFO status observations at physical 005f688c.
One supported read consumes one unchanged word. Exhaustion returns host -4 at
the reached instruction; missing or rejected input retains partial guest state.
The caller must retain the observation array until reset or reconfiguration.
Writes to this status input and unsupported reads are rejected without mutation.

The reached word at physical 00702c00 uses declared little-endian host storage.
Aligned byte/word/longword reads and writes preserve unaffected bytes and share
the same value across physical/P1/P2 aliases. This storage is not an electrical
device model, audio output, physical reset, FIFO implementation, G2 arbitration,
IRQ delivery or automatic completion. Prior scan, A/V, CCR, register and cache
policies remain explicit. Actual presentation timing and 60/120/240 FPS are
future PC port work. The requested graphics/settings/other ports remain pending.
