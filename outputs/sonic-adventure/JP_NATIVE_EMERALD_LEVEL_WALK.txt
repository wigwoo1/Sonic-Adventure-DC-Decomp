Native Sonic level-ground walking in Emerald Coast

The new walking step follows the level-ground path of the Japanese Sonic
update. It uses the native floor query for contact and advances animation,
the collision shape and position history. Its scope is ordinary grounded
walking. The harness still polls input and selects the walk path.

Build with build_native_emerald_level_walk.py using the verified update
frame build. Run verify_native_emerald_level_walk.py with the same local
disc, collision and character inputs. The active-input part of the ring
approach uses the new function. The Windows build compiled, linked and
passed 600 checks. It awarded one ring and reproduced both prior captures
byte for byte.

Full Sonic mode dispatch and general collision remain integration work.
Overall project completion is about 10%.
