Original-model runtime inputs and limits
The initialized-object integration retains the native constructor's shipped
models and animation data. Renderer scratch records are relocated into an
isolated f00000..ffffff RAM arena, away from the original object heap. The
camera/view record is separately supplied at 8ce90000. Valid renderer masks,
projection/light/basis values, command buffers and texture metadata are input
fixtures, not proof of natural renderer/player initialization.

Zero-valued render masks must be initialized explicitly: the older state-only
tests deliberately used arbitrary bit patterns. Retaining their OR mask would
force a textured primitive profile onto meshes with no UV stream. That test
setup error was corrected without changing original geometry or UV pointers.

The secondary drawing path selects the shipped texture list at 0ca53c14:
221 name records at 0ca531b8. Their on-disc runtime descriptor slots are zero.
The comparison supplies valid descriptor pointers while retaining the original
filenames and attribute words. A separate 256-entry supplied runtime table is
also available for selected texture lists. Real texture loading, GPU sampling,
asset upload and the final HD/texture-off settings remain unfinished.
The native queue trace stores the first 4,096 events per invocation. Caller
checks compare that entire stored prefix, the dropped-event count, final queue/
QACR/counters and all reached/final guest RAM. Events beyond the stored prefix
are not individually compared; final packet RAM is still compared in full.

The queue reference is a bounded coherent-RAM/MMU-off software model. It checks
queue/QACR state, invalidations, prefetch/write-back events and destination RAM,
not physical cache timing, MMU/TLB behavior or GPU FIFO rendering. Vector
numerical comparisons retain the separately qualified pinned core; the exact
dyadic preprocessing oracle is independent. Existing lower routines retain
their documented valid-RAM, narrow-FPU, count/lookahead and pointer contracts.
Natural scene setup, whole frames, gameplay, high-FPS/8K/SUPIR and playable
ports remain unfinished. The AL_MAIN parent stays unregistered until all of
its paths and dependencies are recovered and verified.
