What the software register store proves
It stores accepted values and records ordered reads/writes in an explicit bounded
address window, while retaining the existing QACR/store-queue behavior. It does
not execute GPU commands, emulate hardware status/acknowledgements, render pixels
or implement timing/interrupts/read-only register rules. That platform work remains
necessary for a playable PC port. The successful view proof is limited to its
actual register writes; it does not rely on invented hardware read responses.
