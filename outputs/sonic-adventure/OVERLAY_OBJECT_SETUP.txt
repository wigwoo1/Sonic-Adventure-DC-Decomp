Observed behavior
Walkers flatten every node in preorder: current node, child subtree, sibling
subtree. Flags do not suppress nodes. The recursive walker returns the next
index; the root wrapper leaves the original incidental R0 behavior unchanged.

The clone allocates a 52-byte object and optional 40-byte model. It copies model
positions and normals (vertex count times 12), materials (count times 20), and
segments (count times 24). Only the FIRST segment's auxiliary normal buffer
receives an additional copy (its group count times 12). Index streams, UVs and
remaining segment subpointers stay shallow. This is not a universal deep copy.
Children and siblings are cloned recursively; a descendant allocation failure
stores a null pointer without rolling back an already allocated parent.

Failure cleanup intentionally follows the original asymmetry. In particular,
failure of the first-segment auxiliary allocation can retain the segment table
when there are no materials. The repeated material-pointer test after freeing
that separate allocation remains nonzero under the valid heap contract. These
behaviors are preserved and documented rather than silently repaired.

Object setup stores original auxiliary pointer 0ca53c14 at entity+7c4, maps
appearance type 7 to type 0, and selects six original roots from table 0c91c3d0.
It clones the first root and writes seven preorder tables (clone plus six
original roots). Every shipped root examined has 39 nodes. Entity offsets are
248 for the clone pointer, then 24c/314/3dc/6fc/4a4/56c/634 for the tables (hex).
It executes FLDI0 FR3 and an original raw FMOV at entity+d4. Wide transfers use
the inactive FR2 pair as the original odd-register encoding requires; raw
neighboring-word effects are preserved. PR=1 is guarded at FLDI0 before effects.

Appearance bit 40 invokes 0c904aea and then continues. Bit 04 tail-calls
0c904bbc, otherwise bit 08 tail-calls 0c904c80. Tail branches restore original
PR, stack and saved registers before transferring. The three variants remain
explicit state-mutating fixtures; they are not recovered in this checkpoint.

Coverage exclusions
The null-source branch at 0c904536/538 is not executed: the preceding BF/S delay
slot at 0c904534 first reads source+4, outside modeled RAM when source is null.
Native code stops before that invalid read, preserving the reached partial
state. Both walkers similarly stop before a null-node child read, after the
original output-table write. This models a boundary, not hardware exceptions.
The two excluded conditional outcomes are the null-source branch and the
repeated material-null test under valid separate allocations. No dynamic
coverage is claimed for either; all 465 exported rows remain byte checked.
