positive key spans. The native implementation uses the existing qualified vector
numeric backend; its original-instruction reference uses the documented numerical
model. Analytic vector checks allow 2e-5 absolute error and angle checks one
integer unit. These are not claims of arbitrary Dreamcast hardware bit equality.
Existing scalar/vector/sqrt, enabled-exception, MMU-off valid-RAM and legacy mode
limits remain. No interpolation result or game-service return is injected.
