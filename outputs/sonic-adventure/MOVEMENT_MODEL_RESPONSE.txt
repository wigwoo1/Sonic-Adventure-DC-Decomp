Recovered behavior
The movement routine takes an actor through R4, a 132-byte query through R5,
and an external flag/object-ID record through R6. The actor byte at +8 selects
the original velocity/state pointer tables. It saves the query through the real
copy routine, calculates offsets with existing movement/rotation helpers, updates
the query, and applies angle, length, speed and radius conditions. It invokes the
actual collision owner and either commits selected changes or restores the saved
query. The debug branch runs the real renderer and hardcoded original model.

The traversal reads type from the low three node flag bits. Types 0..7 select
the original translation, rotation and scale combinations. Bit 8 suppresses
drawing; bit 10 suppresses children; bit 20 selects rotation order. The child
pointer is at +2c, sibling at +30. The real 037098 mesh callback runs in order.
The wrapper executes render-state save, traversal and a tail call to restore.
Addresses, offsets and bit masks in this guide are hexadecimal.

Reachability and precision limits
The type selector is ANDed with 7 and tested against 7,0,1,2,3,4,5,6. Therefore
BF 036c12 cannot reach 036c18. That branch and its delay-slot NOP at 036c1a
are unreachable from normal entry with fixed original code. This covers every
32-bit node flag word and assumes no separate-buffer requirement.

The second proof has a narrower, explicit numerical scope: PR0/SZ0, the current
ordinary scalar software contract. To reach the repeated comparison at 074624,
an earlier test must have established cap > speed. The admitted path makes no
RAM stores or calls and rereads the same words. The later speed > cap cannot
then be true. Thus 074626 -> 074644 is infeasible within that profile.

This is NOT a universal proof for arbitrary physical SZ1 execution or foreign
callbacks that change precision. That broader precision outcome remains an open
project obligation. Existing native backends reject unsupported PR/SZ profiles;
selected raw modes are tested as reached stops. No new precision guard, input
exclusion or source deletion was introduced. Physical FPU/MMU/exception behavior
and arbitrary mid-function entry remain unqualified.
