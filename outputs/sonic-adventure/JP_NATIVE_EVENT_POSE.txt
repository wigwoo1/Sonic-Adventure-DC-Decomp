What changed
The existing Frame owner now includes the genuine whole/_in_floors/floorf
runtime bodies, the core pose walker and getters, original angle_difference,
player_get, player_weld and event_motions_draw. Eleven original source functions
compile from the pinned external source. Compilation is not proof that every
linked path works:player_weld and event_motions_draw remain runtime-unqualified.
The original debug pose-axis drawing functions are outside this selected unit.

The SDK floor code uses an authored integer conversion bridge for its original
finite |x|<2^32 whole() branch. This preserves SH4 FTRC saturation and FLOAT
rounding toward zero, signed zero and denormal behavior without undefined host
float-to-int conversion. Existing scalar RZ services handle its comparison/add.
The native API is value-only with RM=1,DN=1. FPSCR flags,traps and arbitrary
host rounding modes are not emulated or qualified by this work.

The SDK's errno data uses the same existing jp_sdk_errno owner already used by
original print formatting. It is not Windows CRT's _errno() function. No second
SDK error variable or player_records array is created. The exact original
player_work BSS declaration is compiled with native pointer width. Its full
player/task lifetime integration remains unfinished. _NIFONES is the actual
original32-bit constant definition; host word width is asserted.

Native pose units retain the original matching bodies. Two unused matching
spelling casts of an angle to an address are explicitly zero-extended before
forming the native pointer. They remain unused; real model/key pointers retain
their native width. Only actual COFF COMDAT Any compiler floating constants may
share definitions. Genuine duplicate state or functions are still rejected.
