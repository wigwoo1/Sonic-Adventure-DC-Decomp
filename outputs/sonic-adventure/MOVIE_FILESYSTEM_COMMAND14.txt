Recovered behavior
Command 14 reads file blocks starting at an offset. Original worker APIs pass
caller stack argument 0 as offset and stack argument 1 as requested block count.
A zero requested count queries the original file size and subtracts the offset.
The handler opens a read handle, sets progress counters, seeks through the FAT,
reads the requested number of blocks, and closes the handle. Each block is 512
bytes. Read errors propagate; the original close return is ignored.

The seek helper resets its current block to the handle head, then follows FAT
links once per skipped block, decreasing the handle's remaining-block count.
It does not restore that remaining count before seeking. Repeated-call semantics
are retained; this is not replaced with a modern seek implementation. Reaching
end marker FFFA with zero remaining blocks returns zero. An end marker with
nonzero remaining count, or zero remaining count before an end marker, returns
-65536. The master ignores seek's result. Thus an empty file with explicit
positive offset/count can complete successfully with the caller buffer untouched.

The read helper returns zero at EOF. The master still performs its requested
number of helper calls, even when later calls copy no bytes. The tests distinguish
those calls from real device read attempts. Explicit counts beyond the remaining
file therefore leave the buffer tail untouched rather than submit extra reads.
First and later raw read errors return -255 and preserve the already copied prefix.

Automatic-count arithmetic has an important input limit: offset greater than file
size wraps the subtraction modulo 32 bits and can produce an enormous read loop.
The original subtraction and unsigned loop remain intact. Completed-task tests
cover automatic offsets up to file size and bounded explicit counts, including
explicit offsets beyond EOF. They do not prove completion or performance for the
automatic-count underflow case, arbitrary malformed metadata or concurrent device
histories. No new wait limit or fabricated return hides that unfinished domain.
