Behavior
The helper accepts three vertex-record pointers in R4/R5/R6 and an output queue
cursor in R8. For records without the near flag it reconstructs camera-space
coordinates from projected X/Y and reciprocal depth using the original global
scales and offsets. Near-flagged records already contain camera-space X/Y/Z.
It tests orientation using the original scalar arithmetic and the cull-control
word at 8c8902fc. Accepted input clears that word, clips each edge against the
near plane, retains inside vertices and interpolates crossing vertices. It then
reprojects intersections, stores the temporary polygon, emits three or four
32-byte packets and advances R8 and the emitted-vertex counter.
The four-vertex result uses strip order 0,1,3,2 relative to polygon perimeter
order. Packet control/material words and the final f0000000 marker are preserved.
This ordering was confirmed against original instructions before correcting the
independent test oracle; native C already matched the original executor.

Reached unsupported-transfer guard
