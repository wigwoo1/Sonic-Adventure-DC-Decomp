What changed
The complete original sdk/sofdec/adx_fs.c now links into the existing native
sound module with20 original ADXF exports. It uses the real ADXSTM/GDFS file
layer for archive-header loading, file-range selection and asynchronous reads.
It shares the same System, creator thread, sound lock and elapsed-time service.
No second archive catalog, file pool, clock or audio output client exists.

The original16 ADXF file records and256 partition roots remain authoritative.
Native lifecycle APIs own guarded partition-work allocations and report their
sizes. Loading/replacing/adding a partition uses the actual original parser;
a rejected load restores the previous actual root and releases temporary work.
Successful replacement retires its previous owned storage. Added archives retain
their original next links and entry precedence. Unload detaches the real table
and releases only native-owned storage. Already-open file handles contain copied
frame addresses/sizes and can continue reading after table storage is freed.

The parent archive owner prevents independent lower ADXSTM shutdown while active.
Global sound shutdown closes actual ADXF reads/temporary joints first, detaches
partition roots and frees owned work, then retires lower streams/RNA/G2 before
System closes the borrowed filesystem. Unrelated lower streams are preserved
by ADXF initialization and explicit ADXF shutdown. Raw SDK interfaces remain
internal and require proper caller-owned buffer and lifecycle contracts.
