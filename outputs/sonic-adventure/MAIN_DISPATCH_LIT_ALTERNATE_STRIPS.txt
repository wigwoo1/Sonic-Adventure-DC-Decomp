Behavior
Both helpers walk positively bounded indexed triangle strips, handle the strip's
orientation bit, alternate winding and reject hidden triangles. The second also
checks common clip masks and uses native lighting near helper 8c612e64 for mixed
near-plane triangles. Both call the existing empty stub 8c611708. These reused
dependencies receive no duplicate recovery credit.

For ordinary emitted vertices the original code temporarily switches FMOV width,
uses paired transfers to read lighting/material parameters from the other FPU
bank, and computes a FIPR vector dot product. It subtracts that from the supplied
base, saves the factor at cache+1c and executes OCBWB for that address. The output
packet retains alpha and scales the three RGB words by the lighting factor.
The two helpers preserve the original strip grouping, control words, counters
and queue advancement. As in the earlier flat family, the first output counter
counts emitted vertices plus closed groups; the clipped path adds input strip
lengths, with additional output counted by the near helper when reached.

Portable cache interface
The new source/vertex_bus_lighting.c retains the previous queue/backend ABI and
adds explicit cache operation 2 for OCBWB, recorded as event kind 6. RAM is already
coherent in this bounded backend, so it records the operation without simulating
physical cache lines, dirty tags, latency or fault dispatch. Older backend source
and DLLs are unchanged. This follows the OCBWB write-back classification in the
Renesas SH-4 Software Manual, sections 4.3.8 and 9 (instruction descriptions):
  https://www.renesas.com/en/document/mas/sh-4-software-manual
This reference does not turn the software backend into hardware emulation.
