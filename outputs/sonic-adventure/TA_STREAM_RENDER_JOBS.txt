What changed

ta_stream_jobs_store.c retains the previously qualified capture core as an exact
prefix and adds owned interval copies, generation restoration, submission
cursors and temporary contiguous raster input. The original ta_stream.c and
its 64-packet-page implementation remain preserved. Actual storage still grows
by owned pages. A fixed frame array has not been enlarged.

stream_pixel_jobs.c captures an immutable packet interval at the actual original
render-start register write. It prepares a candidate copy before the parent
bus write, commits ownership only after that write succeeds, and releases the
candidate on failure. Guest list-init can retire active pages without changing
the submitted job. Reset cancels live work without declaring it complete.

Native pixel work materializes the complete owned input, preserving header and
strip continuity across page boundaries. It retains the existing raster math,
format/viewport guards and two-pass validation before pixel mutation. Only the
former fixed input-length restriction changes to the validated owned-input
counter range. The independent oracle receives the same complete input and
retains its previous rational raster math. The old bounded renderer and its
earlier builds remain available with their original bytes and hashes.

The native completion function runs only after successful complete raster work.
Unsupported input, allocation failure or a wrong job identifier cannot produce
fake completion. Texture Off bypasses VRAM conversion and sampling and uses
vertex/material colours. Serialized matched job seeds contain no host pointers;
they restore the actual immutable packet content into new native-owned pages.
