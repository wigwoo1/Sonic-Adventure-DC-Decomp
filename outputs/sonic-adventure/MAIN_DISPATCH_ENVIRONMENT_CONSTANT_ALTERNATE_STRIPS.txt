Behavior recovered
The helpers walk bounded indexed triangle-strip streams, alternate orientation,
reject back-facing triangles, emit queue packets and maintain grouping/input/
output counters. The clipped helper also rejects common screen-outside flags and
calls native near clipper 8c61295a for near-plane crossings. Both call the original
four-byte empty stub 8c611708, reused with no additional recovery credit.

Ordinary output transforms cached normals with the prepared inactive FPU-bank
matrix. The parent scales the first two matrix columns by one half and installs
one-half UV offsets. The FTRV result supplies U and V; explicit FLDI1 replaces the
factor with 1.0 for every emitted vertex. Lighting/ambient values do not supply
that factor. No normalizer is called. Original matrix-bank behavior is retained.

Crossing output instead uses the clipper's published memory matrix through
8c890238. Initial normal-derived UVs are quantized to signed low 16-bit integers;
intersections interpolate and quantize again, then scale by 1/256. These are two
distinct original UV paths. Every clipped output factor is also exactly 1.0.
Quadrilaterals use strip order 0,1,3,2; the last vertex carries f0000000. The final
packet word remains untouched. Inputs are preserved; these helpers do not issue
cache writeback operations. Original queue/counter/cursor side effects remain.
