Compiled native core bootstrap from the Japanese source order
Qualified 2026-11-05. Whole project approximately 10%; goal remains active.

What changed
The real sbInitSystem entry now runs compiled native C. It creates the actual
guarded 1MiB SDK heap, native Ninja/device/window, configured keyboard/controller
or explicit sample source, RTC and original GDFS. It checks each result, keeps
the original eight bounded filesystem attempts, and checks the SONICADV directory
change. The original void SDK entry returns on success; failure unwinds owned
services and exits with a nonzero code instead of continuing into broken startup.

The factory copies native settings and the full disc-track path. Callback/context
providers remain borrowed until cleanup. It refuses preexisting core owners and
foreign/reentrant lifecycle changes. It borrows already initialized empty native
render queue/frame/texture prerequisites; their creation is not claimed as part
of this core function. The higher-level main initializer remains unfinished.

Original platform assumptions and native replacements
The original sbInitSystem uses a last-megabyte console address derived from
_BSG_END, 32-bit buffer alignment, SH interrupt masks, hardware-register/DMA,
cache/store-queue/timer initialization and a console peripheral bus. The native
factory allocates actual pointer-sized memory, reuses the qualified PC device's
GPU/window/QPC/logical frame service, and configures real native input and media.
No successful syHwInit, syHwInit2, _BSG_END or SH interrupt-mask stub is exported.

The original cache_ram_init, cache_ram_restore and cache_ram_end entries really
begin RTS/NOP and return immediately. Twenty-four complete unhooked instruction
calls verify their unchanged registers/SR and return address. Their unreachable
hardware code is not executed on PC. Source hashes for main.c, sbinit.c, cache.src
and SDK syhw.c remain pinned to upstream25a3d3154dbe657325e97dbe8c5291086f6af5c0.

Actual resource ownership and early exit
Core resource mask:245762 (SDK heap, device, input, RTC and GDFS).
After successful initialization, a real native cleanup callback handles early
sbExitSystem/syBtExit before the main caller has finished creating its remaining
services. Its observation bit is JP_EXIT_BOOTSTRAP=262144; regular bind cannot
accept that bit. This temporary registration invokes no synthetic initialization
and is creator-thread owned. Ordinary pre-handoff shutdown cancels it and permits
restart. Actual early exit becomes terminal and safely retries retained resources.

Final handoff goes through jp_system_bind_exit with a mask covering every owned
core service plus the caller's explicitly acquired additional owners. Successful
handoff removes the temporary registration and gives the existing native exit
service the terminal tokens. Full tested composition uses247798. Legacy masks
and public exit struct sizes retain their meanings. GDFS closes before RTC,
input before window/device, and the final SDK heap after selected consumers.

Failure qualification found and fixed a real rollback issue: a failed RTC
constructor can have no callback to shut down. Cleanup now inspects actual RTC
state and clears its borrowed provider, instead of interpreting an uninitialized
clock's shutdown error as a still-live callback. A missing live handler still
fails explicitly and retains ownership; that case is not silently bypassed.
