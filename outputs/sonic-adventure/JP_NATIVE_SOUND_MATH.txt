What changed
The actual sound graph now provides njSin, njCos, njSqrt and
vector_length_squared. Sine/cosine preserve the original low-16-bit angle and
FSCA behavior. Vector length follows the original four-lane FIPR with a zero
fourth component. Square root imports the existing frame DLL's integer square
root provider and preserves the original signed-root behavior: negative normal
values return -sqrt(-n). Signed zeros, DN subnormals, infinities and unordered
NaN comparisons follow their original branches. Fixed RZ/DN1 value semantics
do not emulate FPSCR side effects or establish new hardware measurements.

Four private header declarations now explicitly import camera_work,
event_skipping, frame_redrawing and pad_records from the existing frame DLL.
Original declaration types are preserved. The game sound consumer uses those
headers; no duplicate camera, flag or controller-record globals are defined.
Relative GCC header includes are preserved by keeping the src/gcc directory
relationship in the private overlay. Sound API identities retain the existing
native intptr_t policy; all full-module callers must use the same native header.
