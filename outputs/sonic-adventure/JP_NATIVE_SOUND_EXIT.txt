Shutdown authority
- Sound issues a monotonically increasing token to the creator thread. Ordinary
  sound configure/init/shutdown cannot replace or retire a claimed owner. Real
  service/render/pump remain usable until delegated cleanup starts.
- System reserves the sound bit in its existing bootstrap registration BEFORE
  sound startup, then attaches its actual token after the original startup
  succeeds. A partially failed startup cannot lose that cleanup obligation or
  be omitted from a final resource mask.
- Ordinary System shutdown unbinds sound callbacks, finishes actual G2/SDK/
  AICA/output work and releases driver staging before GDFS, RTC, input, device/
  wait and finally the SDK heap. The closed sound claim remains held until all
  borrowed core cleanup and bootstrap cancellation succeed. It then releases
  for a real same-process System and original sound restart.
- Early exit uses that SAME System bootstrap callback, commits terminal sound
  authority and closes in the same order. Final bind transfers the same token
  with the core owners; it does not try to claim sound twice. Failed validation
  or a later device claim rolls back newly acquired claims without cancelling
  the bootstrap's existing sound authority. A new independent sound claim is
  cancelled if a later final claim fails.
- A failed sound close stops before any borrowed filesystem/clock/device/heap
  cleanup. Failed or partial cleanup keeps its token and unfinished allocations
  for a creator-thread retry. Terminal exit cannot restart or cancel sound.
  If ordinary audio close succeeded but filesystem close later failed, a later
  early exit commits the already closed sound claim without closing it twice.
- A guard on the exact existing bootstrap registration rejects nested global
  cleanup/bind before it can mark terminal exit started. This preserves normal
  bootstrap cancellation/restart when a real completion callback reenters exit
  during local System shutdown. Final cleanup likewise rejects recursion.

Existing API layouts and every legacy resource mask remain unchanged.
JP_EXIT_SOUND is the explicit new bit524288. The observation-only bootstrap
bit262144 is still rejected as a bind resource. CORE245762 and full247798 retain

Including sound is explicit; legacy graphics-only callers do not implicitly
initialize/claim audio. Native sound options56/info104 and System options96/
info64 stay unchanged. Additional sound claim info is32 bytes.
