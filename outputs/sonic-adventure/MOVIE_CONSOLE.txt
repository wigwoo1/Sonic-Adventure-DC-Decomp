Native host service, not decompiled BIOS
source/native_console_service.c/h adds a separate API using immutable borrowed
24-byte information and flash byte spans. No default identity/flash image is
manufactured. Binding writes only the configured sysinfo/flash vector slots,
8c0000b0 and 8c0000b8, using distinct native markers 8c00f110/8c00f120. The older
disc service and all original game adapters retain their bytes and behavior.

Info selector zero copies the explicit information bytes to guest 8c000068..7f;
void initialization preserves R0. Selector three returns that guest pointer after
initialization. Flash selector one copies requested bytes from the supplied
read-only image, returning its byte count or guest -1 for an out-of-range read.
Invalid pointers/aliases and unsupported/unconfigured operations remain host
stops without manufactured success. Input spans cannot alias guest RAM and stay
borrowed/immutable until reconfiguration. Guest RAM must be a stable sixteen-MiB
array. Host output/state storage must be valid and separate from guest inputs.

These are explicit native platform choices, not physical BIOS measurements or
recovered BIOS scratch-register clobbers/data extraction. Raw test bytes are
invented records, not authentic console data. Vector binding is host setup, not
a claim that original reset produced those pointers. Writable flash, erase,
icons/fonts and other selectors remain unsupported. No missing game callback or
query result is supplied; original game instructions decode the returned bytes.
